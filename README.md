Deal or No Deal Burque Edition
Welcome homie to the ultimate 505 game of chance customized right for Albuquerque. This repository contains a fully responsive single file web based Deal or No Deal game complete with local Burque slang El Banker mechanics custom commercial break integrations and dynamic pop culture cutscenes.
Features
 * Orale Burque Flavor written completely with local 505 slang and attitude
 * Live GPS Restaurant Finder to scan locations within a 25 mile radius and load local spots fast food or sit down chains directly into your game
 * 13 Unique Cutscene Animations featuring local references Sandia Labs the Rio Grande sports teams like the 49ers Bills Dolphins Patriots and magical or theatrical moments
 * Progressive Suspense Engine where screen shakes and background tension shift dynamically as the board gets smaller
 * Fully Automated Endgame Logic with keep or swap decisions and automatic elimination reveals
 * Last Chance Gamblers Pass allowing players to roll the dice for an all or nothing upgrade when their final case falls below the board average
 * Seamless Commercial Video Uploads with autoplay compatibility and mobile touch fallbacks
Commercial Breaks System
The game features an immersive broadcast style commercial break system that replicates live television pacing. When starting up players can toggle commercial breaks on and choose to upload custom video files for specific milestones throughout the match.
 * Mid Game Commercial One triggers automatically right after the eighth briefcase is opened
 * Mid Game Commercial Two triggers automatically right after the twenty second briefcase is opened
 * Finale Commercial Three triggers at the very end of the game if the contestant's final winning case value falls below the overall board average before heading into the Last Chance round
The video player is built with modern mobile browser compatibility in mind. It attempts to play seamlessly right out of the briefcase tap event and includes a backup touch anywhere fallback so playback starts instantly without requiring separate interaction buttons.
Getting Started
To get this game running on your machine or deployed on GitHub Pages follow these simple steps
1 Clone the repository or download the index file
2 Open the index html file in any modern web browser
3 Choose whether you want to enable commercial break videos
4 Pick a preset like Tablet Time Toy Run or live GPS Nearby Restaurants or manually enter your 25 custom items
5 Enter the contestant name and get down
